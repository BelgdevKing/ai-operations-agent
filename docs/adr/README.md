# Architecture Decision Records

One file per significant decision, named `NNNN-short-title.md`.

Record a decision here when it is hard to reverse, constrains later work, or
when a reader would otherwise ask "why was it done this way?". Routine choices
belong in [../architecture.md](../architecture.md), not here.

## Template

```markdown
# NNNN - Title

- **Status:** proposed | accepted | superseded by NNNN
- **Date:** YYYY-MM-DD

## Context
What forced a decision.

## Decision
What was decided.

## Consequences
What this makes easy, what it makes hard, and what has to be revisited later.
```
